# DORA

**Fuente:** SRC-DORA-001/002, evidencia de investigación. DORA orienta mejora por
capacidades y cinco métricas: lead time, deployment frequency, failed deployment
recovery time, change fail rate y deployment rework rate. No es estándar ni impone
umbrales.

Para SDC-002 se usa únicamente la capacidad **Continuous Integration**: integración
frecuente en una línea compartida y pruebas automatizadas rápidas como evidencia para
reducir riesgo de integración. DORA no define un check obligatorio, ni un porcentaje
de cobertura, ni una política de merge.
