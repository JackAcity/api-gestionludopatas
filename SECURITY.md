# Politica de seguridad

No publiques credenciales, API Keys, tokens de Vault, cadenas de conexion, datos personales
ni capturas que los contengan en issues, pull requests, comentarios o logs.

Para un hallazgo de seguridad, abre un **GitHub Security Advisory** de borrador en este
repositorio y agrega a `@JackAcity`. Si no tienes permiso para ello, contacta primero al
mantenedor por el canal interno acordado. Un issue normal solo puede registrar una version
sanitizada del incidente despues de contenerlo.

La respuesta inicial debe incluir: alcance, evidencia sanitizada, severidad, mitigacion
temporal, propietario y fecha objetivo. Toda correccion pasa por el CI/DevSecOps y conserva
una estrategia de reversa.
