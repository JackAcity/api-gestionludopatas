# Adaptador GitHub: gobierno de repositorio (propuesto)

Mapea SDC-001: ramas confiables protegidas, PR para integración, checks de fuente conocida, conversaciones resueltas, CODEOWNERS para rutas críticas y bypass explícito/auditado. La exigencia de aprobaciones depende del perfil y de que exista un revisor distinto al autor; no se simula separación de deberes con una misma cuenta.

Verificación requerida: snapshot de ruleset, caso de merge fallido, caso de modificación de `.github/` y evidencia de que un bypass queda registrado. No activar hasta aprobar perfiles, equipo y capacidad del plan.
