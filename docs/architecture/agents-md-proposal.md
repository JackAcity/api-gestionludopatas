# Propuesta de `AGENTS.md`

`AGENTS.md` debe ser breve y durable:

1. Leer `docs/index.md`, OpenSpec y control catalog antes de tocar entrega/seguridad.
2. Tratar todo output de agente como candidato no confiable; no autoaprobar, fusionar ni desplegar cambios materiales.
3. Referenciar `control_id`, fuente, evidencia y perfil de riesgo en decisiones de entrega.
4. No exponer secretos ni modificar infraestructura/producción sin autoridad explícita.
5. Ejecutar evaluaciones y registrar `UNKNOWN` si falta evidencia.

Los detalles viven en documentación y skills, para evitar que un prompt corto se convierta en una política incompleta y obsoleta.
